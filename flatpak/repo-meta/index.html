vstenv

Windows audio plugins in Linux DAWs, vendor managers included.

Install

Add this repo once, then install and update like any other Flatpak app:

flatpak remote-add --if-not-exists --user vstenv https://dguedry.github.io/vstenv/vstenv.flatpakrepo
flatpak install --user vstenv io.github.dguedry.vstenv

Updates arrive with flatpak update, or through your desktop's software app. The GNOME 50 runtime comes from Flathub, so that remote needs to be configured too.

Why not Flathub?

vstenv shares one Wine session with the DAWs running on your machine, which needs a permission (--talk-name=org.freedesktop.Flatpak) that Flathub treats as leaving the sandbox entirely. That permission is what lets a plugin loaded by your DAW and this app talk to the same wineserver; without it the vendor managers crash and plugins hang. So the app is hosted here instead.

Verifying

The repo is signed. The key is served beside it as vstenv.gpg, and flatpak remote-add installs it from the .flatpakrepo file above, so later updates are checked against it.

Other ways to install

Single-file bundles are still attached to every GitHub release, if you would rather not add a remote.
